# PmmoJS 文档首页

`PmmoJS` 用来在 Forge `1.20.1` 上连接 Project MMO 与 KubeJS。

建议从这些页面开始：

- [概览](./overview) 了解功能范围与脚本绑定
- [启动事件](./startupevents/registry) 查看 predicate、perk 注册与直接 PMMO 注册
- [服务端事件](./serverevents/settings) 查看 PMMO 设置、配置修改、运行时桥接与内部钩子
- [标签模型](./tag-model) 理解 perk 标签、运行时上下文标签与配置标签生命周期

如果你想先清掉一部分 PMMO 默认数据，再只加回自己需要的内容，请看 [清空默认数据](./serverevents/reset-recipes) 以及 Forge 通用配置文件 `config/pmmojs-common.toml`。
