# 配置事件

这些事件允许你在 `server_scripts/` 中直接调整 PMMO 配置数据。

## 通用配置：`config/pmmojs-common.toml`

在 KubeJS 配置事件执行之前，PmmoJS 可以先通过 Forge 通用配置关闭 PMMO 自带的默认数据。

当你想让整合包从更干净的基线开始，而又不想在 `server_scripts/` 里复制一大段重置脚本时，这就是首选方案。

```toml
[disableDefaultSettings]
all = false
skills = false
perks = false
requirements = false
xpAwards = false
itemExtras = false
blockVeinData = false
```

执行顺序：

1. PmmoJS 读取 `pmmojs-common.toml`
2. 按开关清掉对应类别的 PMMO 默认数据
3. 再执行 `PmmoJS.skillsConfig(...)`、`PmmoJS.perksConfig(...)` 与 `PmmoJS.settings(...)`

也就是说，通用配置负责清底，你的脚本仍然会在后面覆盖并补回自定义内容。

## `PmmoJS.skillsConfig`

用于添加、替换或移除 PMMO 技能。

```js
PmmoJS.skillsConfig(event => {
    event
        .addSkill('defense')
        .withColor(0x2f6fed)
        .withMaxLevel(100)
        .withIconSize(18)
        .build()

    event.removeDefaultSkill('swimming')
})
```

如果同一次处理里先移除再添加同名技能，最终会以你自定义的技能定义为准。

## `PmmoJS.globalsConfig`

用于管理 PMMO 的全局数据，例如可复用的 NBT 路径与常量。

```js
PmmoJS.globalsConfig(event => {
    event.addPath('durability', 'Damage')
    event.addConstant('MAX_SKILL_LEVEL', '100')
    event.removePath('old_path')
    event.removeConstant('OLD_CONSTANT')
})
```

## `PmmoJS.perksConfig`

用于编辑已有的 PMMO Perk 数据。

```js
PmmoJS.perksConfig(event => {
    event.clearPerks(EventType.SKILL_UP)
    event.removePerkType('pmmo:fireworks')
})
```

核心控制方法：

- `addPerk(eventType, perkId, skill)`
- `clearPerks(eventType)`
- `removePerkType(perkId)`
- `removePerk(tag)`

配置合并行为：

1. PmmoJS 先复制 PMMO 当前的 `PerksConfig.PERK_SETTINGS`
2. `clearPerks(eventType)` 会把该事件类型的列表直接清空
3. `removePerkType(perkId)` 会跨全部事件移除匹配 `perk` 的条目
4. `removePerk(tag)` 按 `perk` 与 `skill` 两个字段匹配移除
5. `addPerk(...)` 会把新的 perk tag 追加到指定事件列表

builder 会写入的基础 key：

| 方法 | 写入的 Key |
| --- | --- |
| `addPerk(eventType, perkId, skill)` | `perk`、`skill` |
| `withCooldown(...)` | `cooldown` |
| `withChance(...)` | `chance` |
| `withMinLevel(...)` | `min_level` |
| `withMaxLevel(...)` | `max_level` |
| `withPerXLevel(...)` | `per_x_level` |
| `withMilestones(...)` | `milestones` |
| `withString(...)`、`withBool(...)`、`withInt(...)`、`withLong(...)`、`withFloat(...)`、`withDouble(...)` | 自定义标量 key |
| `withStringList(...)` | 自定义字符串列表 key |
| `withList(...)` | 原始 `ListTag` key |
| `withCompound(...)` | 嵌套 compound key |

专用 builder 家族：

下表描述的是每个 builder 在 PmmoJS 中暴露的 key。某个 key 能通过 builder 写入，并不等于 PMMO 会在所有 perk 类型上都解释这个 key。

| Builder | 额外 Key |
| --- | --- |
| `asAttributePerk()` | `attribute`、`multiplicative`，以及 `max_boost`、`per_level`、`base` |
| `asTempAttributePerk()` | `attribute`、`multiplicative`、`duration`，以及 `max_boost`、`per_level`、`base` |
| `asDamageBoostPerk()` | `applies_to`、`for_damage`、`multiplicative`，以及 `max_boost`、`per_level`、`base` |
| `asDamageReducePerk()` | `for_damage`，以及 `max_boost`、`per_level`、`base` |
| `asBreakSpeedPerk()` | `pickaxe_dig`、`axe_dig`、`shovel_dig`、`hoe_dig`、`shears_dig`、`sword_dig`，以及 `max_boost`、`per_level`、`base` |
| `asEffectPerk()` | `effect`、`duration`、`modifier`、`ambient`、`visible`、`show_icon`，以及 `max_boost`、`per_level`、`base` |
| `asCommandPerk()` | `command`、`function`，以及继承得到的基础 key 方法 |
| `asFireworksPerk()` | `colors`，以及继承得到的基础 key 方法 |
| `asJumpBoostPerk()` | `max_boost`、`per_level`、`base` |
| `asBreathPerk()` | `max_boost`、`per_level`、`base` |
| `asVillagerBoostPerk()` | `max_boost`、`per_level`、`base` |
| `asTameBoostPerk()` | `max_boost`、`per_level`、`base` |

示例：

```js
PmmoJS.perksConfig(event => {
  event
    .addPerk(EventType.SKILL_UP, 'pmmo:attribute', 'endurance')
    .asAttributePerk()
    .withAttribute(Java.loadClass('net.minecraft.world.entity.ai.attributes.Attributes').MAX_HEALTH)
    .withPerLevel(1)
    .withMaxBoost(10)
    .build()
})
```

## `PmmoJS.serverConfig`

用于修改 PMMO 的服务端配置值。

```js
PmmoJS.serverConfig(event => {
    event
        .setMaxLevel(100)
        .setGlobalModifier(1.0)
        .setUseExponentialFormula(true)
        .setTreasureEnabled(true)

    event.addSkillModifier('defense', 1.1)
    event.addJumpXp('agility', 0.5)
    event.addPartyBonus('charisma', 0.1)
})
```

## `PmmoJS.autoValueConfig`

用于覆盖 PMMO 的 auto-value 自动生成逻辑。

```js
PmmoJS.autoValueConfig(event => {
    event
        .setAutoValuesEnabled(true)
        .setRaritiesModifier(1.5)
        .setHardnessModifier(2.0)

    event.addItemXpAward(EventType.CRAFT, 'smithing', 25)
    event.addBlockReq(ReqType.BREAK, 'mining', 5)
    event.setAxeOverride({
        woodcutting: 15
    })
})
```

## `PmmoJS.antiCheeseConfig`

用于编辑 AFK 检测、收益递减与标准化等 anti-cheese 设置。

```js
PmmoJS.antiCheeseConfig(event => {
    event.setAfkCanSubtract(false)

    event
        .addAfkSetting(EventType.BLOCK_BREAK)
        .minTime(600)
        .reduction(0.1)
        .cooloff(5)
        .tolerance(3.0)
        .strictTolerance(true)
        .build()
})
```

<Callout variant="info">
    这些配置事件走的是服务端 / 静态数据重载路径，因此能和 PMMO 自身配置重载
    以及 EMI 标签同步流程保持兼容。
</Callout>
