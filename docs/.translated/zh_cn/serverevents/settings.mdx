# PMMO 设置事件

`PmmoJS.settings` 是从 `server_scripts/` 注册 PMMO 对象数据的主桥接入口。

## 单目标 builder

这些方法一次只创建一个 builder：

- `event.item(itemOrId)`
- `event.block(blockOrId)`
- `event.entity(entityTypeOrId)`
- `event.biome(id)`
- `event.dimension(id)`
- `event.generic(objectType, objectOrId)`

对于 `item`、`block`、`entity`，现在既可以传注册对象，也可以直接传注册表 id 字符串。

```js
PmmoJS.settings(event => {
  event
    .item('minecraft:diamond_sword')
    .override(true)
    .setRequirement(ReqType.WEAPON, 'combat', 10)
    .setXp(EventType.CRAFT, 'smithing', 100)

  event
    .block('minecraft:diamond_ore')
    .override(true)
    .setRequirement(ReqType.BREAK, 'mining', 30)
    .setXp(EventType.BLOCK_BREAK, 'mining', 200)

  event
    .entity('minecraft:zombie')
    .override(true)
    .setXp(EventType.DEATH, 'combat', 25)
})
```

## 批量应用 helper

这些方法会把同一个 builder 回调应用到多个目标：

- `event.items(targets, callback)`
- `event.blocks(targets, callback)`
- `event.entities(targets, callback)`
- `event.biomes(targets, callback)`
- `event.dimensions(targets, callback)`
- `event.genericMany(objectType, targets, callback)`

`targets` 可以是：

- 单个 id
- 单个注册对象
- JS 数组
- Java list 或其他 iterable

当你要一次给很多对象套用同一套 PMMO 规则时，这就是推荐写法。

```js
PmmoJS.settings(event => {
  event.items([
    'minecraft:diamond_sword',
    'minecraft:netherite_sword',
    'minecraft:trident'
  ], setting => {
    setting.override(true)
    setting.setRequirement(ReqType.WEAPON, 'combat', 20)
    setting.setXp(EventType.CRAFT, 'smithing', 150)
  })

  event.entities([
    'minecraft:villager',
    'minecraft:wandering_trader'
  ], setting => {
    setting.override(true)
    setting.setRequirement(ReqType.ENTITY_INTERACT, 'charisma', 8)
  })
})
```

## 通用 builder 方法

所有设置 builder 都继承这些常用方法：

- `setRequirement(reqType, skill, level)`
- `requirement(reqType, map)`
- `setXp(eventType, skill, amount)`
- `xp(eventType, map)`
- `override(boolean)`

## 按类型提供的额外能力

根据 builder 的具体类型，你还可以使用：

- 物品回收配置
- 物品与实体伤害类型 XP 注册
- 正负面药水效果注册
- 地点类 mob modifier
- 矿脉连锁充能配置
- NBT requirement、NBT XP、NBT bonus builder

例如：

```js
PmmoJS.settings(event => {
  event
    .item('minecraft:diamond_pickaxe')
    .override(true)
    .veinChargeCap(128)
    .veinChargeRate(1.25)
    .veinConsumeAmount(2)
})
```

## 清空默认数据

如果你想不写脚本就清掉大类 PMMO 默认数据，优先改 `config/pmmojs-common.toml`：

- `disableDefaultSettings.all`
- `disableDefaultSettings.skills`
- `disableDefaultSettings.perks`
- `disableDefaultSettings.requirements`
- `disableDefaultSettings.xpAwards`
- `disableDefaultSettings.itemExtras`
- `disableDefaultSettings.blockVeinData`

设置事件还保留这些旧的辅助方法：

- `clearVanillaItemSettings()`
- `clearVanillaBlockSettings()`
- `clearVanillaEntitySettings()`

应把它们看作需求重置 helper，而不是完整的 PMMO 全量清空接口。

它们只能处理大范围的 requirement override，不能完整重置这些类别：

- XP 奖励
- bonus
- 正负面效果
- salvage
- vein 数据
- biome 与 dimension 设置

重置顺序、脚本写法与 location 限制请看 [清空默认数据](./reset-recipes)。

## 枚举名要以 PMMO 实际版本为准

请使用当前 PMMO jar 里真实存在的枚举名。例如：

- `ReqType.ENTITY_INTERACT` 存在
- `ReqType.ENTITY` 不存在
- `EventType.BLOCK_BREAK` 存在
- `EventType.BREAK` 不存在
- `EventType.DEATH` 存在
- `EventType.KILL` 不存在
