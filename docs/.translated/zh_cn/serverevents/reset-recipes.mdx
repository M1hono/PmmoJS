# 清空默认数据

这一页说明如何让 PMMO 从更小、甚至几乎全自定义的数据集开始运行。

旧的重置示例包不再作为正式工作流的一部分保留。现在推荐直接把下面的写法放进你自己的 `server_scripts/`，或者在适用时优先使用通用配置。

## 首选方案：通用配置

对于 PmmoJS 已经能安全整类清空的 PMMO 数据，优先使用 `config/pmmojs-common.toml`：

```toml
[disableDefaultSettings]
all = false
skills = false
perks = false
requirements = false
xpAwards = false
itemExtras = false
blockVeinData = false
```

可用开关：

- `disableDefaultSettings.all`：开启下面所有受支持的类别
- `disableDefaultSettings.skills`：在 `PmmoJS.skillsConfig(...)` 之前移除 PMMO 默认技能
- `disableDefaultSettings.perks`：在 `PmmoJS.perksConfig(...)` 之前清空 PMMO 默认 perk 条目
- `disableDefaultSettings.requirements`：在 `PmmoJS.settings(...)` 之前清空物品、方块、实体需求数据
- `disableDefaultSettings.xpAwards`：在 `PmmoJS.settings(...)` 之前清空物品、方块、实体 XP 奖励数据
- `disableDefaultSettings.itemExtras`：在 `PmmoJS.settings(...)` 之前清空物品 bonus、正负面效果、salvage 与 item vein 数据
- `disableDefaultSettings.blockVeinData`：在 `PmmoJS.settings(...)` 之前清空方块 vein-mining 数据

顺序很重要：先清默认数据，再执行你的 KubeJS 脚本。所以清空之后，你仍然可以把自己的配置完整加回来。

## 什么时候该用脚本

当你需要的是局部控制，而不是整类清空时，用 KubeJS 脚本更合适。

例如：

- 保留大部分 PMMO 默认内容，只清某一类 requirement，可用 `clearVanillaItemSettings()`
- 只清某一个 `EventType` 下的 perk 列表，可用 `event.clearPerks(EventType.SKILL_UP)`
- 在通用配置清底后，只重建少量物品、方块、实体规则
- 通过显式 id 控制 biome 或 dimension 设置

## 清空后重建技能

如果启用了 `disableDefaultSettings.skills = true`，就需要把真正要保留的技能重新定义出来：

```js
PmmoJS.skillsConfig(event => {
  event
    .addSkill('endurance')
    .withColor(0x2f6fed)
    .withMaxLevel(100)
    .build()

  event
    .addSkill('smithing')
    .withColor(0xe08a25)
    .withMaxLevel(100)
    .build()
})
```

## 清空后重建 Perk

如果启用了 `disableDefaultSettings.perks = true`，就只把整合包真正需要的 perk 条目加回来：

```js
PmmoJS.perksConfig(event => {
  event
    .addPerk(EventType.SKILL_UP, 'pmmo:attribute', 'endurance')
    .asAttributePerk()
    .withAttribute(Java.loadClass('net.minecraft.world.entity.ai.attributes.Attributes').MAX_HEALTH)
    .withPerLevel(1)
    .withMaxBoost(10)
    .build()
})
```

## 清空后重建对象设置

如果你清掉了 requirement、XP 奖励或 item extras，就只把自己的规则重新写回去：

```js
PmmoJS.settings(event => {
  event.items([
    'minecraft:diamond_pickaxe',
    'minecraft:netherite_pickaxe'
  ], setting => {
    setting.override(true)
    setting.setRequirement(ReqType.TOOL, 'mining', 20)
    setting.setXp(EventType.BLOCK_BREAK, 'mining', 12)
  })
})
```

## 旧的需求清空辅助方法

`PmmoJS.settings(...)` 仍然暴露了这些方法：

- `clearVanillaItemSettings()`
- `clearVanillaBlockSettings()`
- `clearVanillaEntitySettings()`

它们只会重置各自对象类型的 requirement 数据，不会清掉 XP 奖励、perk、salvage 或 vein 数据。

## 通用配置故意不覆盖的范围

biome 与 dimension 设置没有提供“一键清空全部默认值”的开关。

这是有意为之。location 数据通常更适合由整合包作者显式列出目标，而不是整表盲清。

需要处理 location 时，请使用 `event.biome(...)`、`event.biomes(...)`、`event.dimension(...)` 或 `event.dimensions(...)` 进行精确覆盖。
