# PmmoJS Documentation

`PmmoJS` connects Project MMO and KubeJS on Forge `1.20.1`.

Use these sections as your starting map:

- [Overview](./overview) for the feature surface and script bindings
- [Startup Events](./startupevents/registry) for predicates, perk registration, and direct PMMO registration
- [Server Events](./serverevents/settings) for PMMO settings, config mutation, runtime hooks, and internal bridges
- [Tag Model](./tag-model) for perk tags, runtime context tags, and config tag lifecycles

If you want PMMO to start from a cleaner baseline, see [Reset Defaults](./serverevents/reset-recipes) and the Forge common config file `config/pmmojs-common.toml`.
