# PmmoJS Documentation

PmmoJS connects Project MMO to KubeJS on Forge 1.20.1.

With PmmoJS, you can control PMMO's gameplay mechanics — skills, experience, requirements, perks, and triggers — directly from KubeJS scripts. No Java required.

## Where to start

If you are new to PmmoJS, read these pages in order:

1. **[Overview](./overview)** — what PmmoJS gives you and how it fits together
2. **[Startup Perk Registration](./startupevents/perks)** — creating custom perks with conditions, lifecycle callbacks, and status display
3. **[PMMO Settings](./serverevents/settings)** — configuring item, block, and entity requirements, XP awards, and bonuses
4. **[Runtime Events](./serverevents/normal)** — hooking into PMMO's gameplay triggers during actual play

## Script types at a glance

| Script folder | What belongs there |
|---|---|
| `startup_scripts/` | Perk registration, predicates, direct PMMO data registration, Forge event listeners |
| `server_scripts/` | Runtime triggers, config editing, gameplay hooks, ProbeJS doc generation |
| `client_scripts/` | Read-only skill display helpers, client-side UI logic |

## Getting a clean baseline

If you want to replace PMMO's default data with your own custom rules:

1. Enable the relevant switches in `config/pmmojs-common.toml`
2. Register your custom data through `server_scripts/`
3. Only the data you define in scripts survives

See [Reset Defaults](./serverevents/reset-recipes) for the full guide.
